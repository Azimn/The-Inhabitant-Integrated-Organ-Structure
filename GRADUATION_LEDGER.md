## Donor families retained without invented integration credit

The native Pretorius Connectome associative implementation was preserved with pinned provenance. No dependency-heavy graph retrieval was placed in the default turn path, because a decision advantage over lexical retrieval was not established. The Calibos mood source is pinned, but the live Affectus uses deliberately simpler sliders. PersonaConsole AETHER is not copied from its zip-only distribution or falsely credited as semantic search, and Gelatinblob's admission gate has not been transplanted without an apples-to-apples efficacy experiment. They remain explicitly unearned research candidates.

DUCK's v0.9 plan object retains its original predefined routes and source-code behavior as an advisory donor. The new canonical action planner is separate, using a bounded search over known affordances and subsequently acquired world evidence. Calling DUCK's original route switch "genuine replanning" would be incorrect.

## Verified acceptance scope

The CI workflows execute an isolated seven-synthetic-day scenario, unit/causal tests, and a Windows run. The active development branch contains all code and manifests. The latest tested head had **19 passing tests on Linux and 19 on Windows**. Earlier red CI heads were repaired, rather than quietly concealed.

## Deliberately open graduation checks

The seven days are simulated, not seven days of wall time. There has been no authenticated frontier-to-local LLM swap with the same subject and no blind human recognition panel, although live Ollama speech and constrained Noesis action ports exist. There is no voice/audio modality implementation. AETHER semantic paraphrase superiority, graph-retrieval downstream efficacy, Gelatinblob admission-gate behavioral learning, full subject-source Sensus ablation, and seven-day complete real-world continuity have not been established. The deterministic synthetic scenario proves a smaller but real cross-organ causal chain, not a finished general artificial individual.

## Measured potato budget

One GitHub-hosted Linux reference run on the implementation branch (not on the user's own laptop) executed 35 physical decisions over seven synthetic days. Approximate measured peak process RSS was 31.4 MiB; peak traced Python allocation was 3.69 MB, worst recorded decision was 24.96 ms, and run state occupied about 1.10 MB including SQLite support files. This run was prior to some later additions, so treat these as reference observations, not guaranteed current ceilings. Windows reports no Unix resource RSS estimate; the fallback reports null, never a fabricated value.
